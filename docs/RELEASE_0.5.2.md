# 0.5.2 自用收尾版

2026-10-15。固定用户认可的连续水面，并整合到主应用。包名 `com.canvas.sjtu.mobile`，版本 0.5.2／5002，Android 10+，ARM64。仍使用此前开发签名，不作为商店正式发行或全功能真机验收通过的证明。

## 本版内容

- 主应用与独立 Demo 共用 `WaterScene` 和 `LiquidSurface`；主应用接收设备传感器，Demo 使用手动模拟输入。
- 保留已认可的配色、透明缸壁和水面材质。完整水体轮廓取代逐粒子亮边，修复蜂窝孔洞；WebGL 与兼容 Canvas 使用相同轮廓重建。
- 省电／均衡／高清均为连续水面，保留倒置、惯性、撞壁、少量液滴及回落。后台和离屏暂停；减少动态效果设置仍生效。
- 设置页与关于页版本直接读取项目元数据，避免显示旧版本。
- 保留原有账号、课程、作业、资料、录播、AI、提醒与手机／Pad 布局；本次不改账号及任务存储格式。
