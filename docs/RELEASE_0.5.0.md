# 0.5.0 开源预览记录

日期：2026-10-15。当前产物用于设备测试与代码评审，尚不标记为稳定版。

## 本轮变化

- 日间与夜间重新配色：参考 Linear、Vercel Geist 与 Radix Slate／Indigo，中性浅灰白与石墨灰背景，统一蓝色交互强调。去掉偏黄绿底色、粉色选中态和低透明度灰字，统一课程、弹窗、设置、AI 与播放器周边。
- 重新整理课程／作业卡片、图标、管理按钮和应用内选择面板；长中文标题换行，移除顶部连接同步条与“本部”品牌标签，精简页面文案。
- 透明圆形水缸使用 Three.js、物理水材质、反射环境与衰减波动；水量按球体体积映射，下方显示提交数量。前台可见时读取重力／加速度，离屏暂停。
- 设置提供省电 30 帧、均衡 45 帧、高清 60 帧三档上限，默认高清，立即生效并持久化。实际帧率由硬件决定；不支持 WebGL 2 的环境使用基础效果。
- 课程、作业、资料目录、录播与字幕按账号及用户身份缓存。启动先恢复缓存，课程切换检查过期资源，手动刷新强制检查；普通同步仅检查所选学期。
- 下载与云盘操作重新向 Canvas 查询文件地址；目录缓存只保存必要标识和大小，不保存鉴权头或旧签名下载地址。
- 录播先按课程卡片浏览；使用 TextureView 与圆角原生播放区域，界面提供统一控制。字幕跟随播放，手动浏览可暂停跟随；提问可选择整堂资料、部分字幕或不附资料。
- 截图来自实际播放器画面；用户发送问题时向其配置的服务传送图片、所选资料及时间位置。文字模型会拒绝图片；服务缺少能力元数据时由实际请求确认。
- 全局助手新增按需读取课程文件的只读工具，先查目录再读相关课件。模型上下文来自服务元数据，缺失时保守回退，容量拒绝时自动缩减重试；不再提供手动预算控件。
- 查询 Canvas 实际日历事件，显示未来七天日程并提供可选提前提醒。没有事件时显示空状态，不能将接口等同于完整教务课表。

## 安装与余项

包名沿用 `com.canvas.sjtu.mobile`，版本 `0.5.0`／`5000`，Android 10+，沿用本机开发签名。公开发行签名和 GitHub 云端构建尚未执行；本轮不创建或推送远程仓库。

真实 Token／jAccount 全链路、真实测试作业与云盘、学校日程是否包含课程安排、实际模型问答、长时间下载／播放、GLES 3 手机与实际 Pad 的全生命周期验收仍待完成。云盘完整上传界面、多套命名模型配置与公开更新源延续既有待办。

本轮 Android 10 模拟器在调整分辨率／密度期间，于 2026-10-15 09:24:10 UTC 留下一次 RenderThread SIGSEGV，栈顶为系统 `libhwui.so` 的 `WebViewFunctorManager::destroyFunctor`。重新启动后恢复，最终安装后的检查未见新的崩溃记录。堆栈位置不能单独证明根因；窗口重建、旋转、分屏与实际 Pad 生命周期仍需进一步排查和验收。

交付文件为 `Canvas-Suixing-0.5.0-preview-arm64.apk`（手机／ARM64 平板）、`Canvas-Suixing-0.5.0-preview-x86_64.apk`（对应模拟器）、`Canvas-Suixing-0.5.0-open-source.tar.gz` 和 `SHA256SUMS-0.5.0.txt`。源码包含 MIT 许可、上游归属、构建文档及工作流，不包含 Git 历史、SDK、账号和签名密钥；基本敏感信息扫描不能代替完整安全审计。
