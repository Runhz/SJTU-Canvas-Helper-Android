# Canvas 随行：手机与平板预览版

同一份 APK 支持 Android 10 及以上手机和平板，只连接交大本部。

- 手机：底部导航，单栏浏览作业、课程、录播与下载。
- 平板：侧栏导航；宽屏下作业概览与截止时间线并排，录播与学习资料并排。
- 小平板／分屏：保留侧栏，内容按可用宽度自动堆叠。
- 浏览器 Demo：打开 http://127.0.0.1:4173/ ，在右上角切换“手机／平板”。示例数据、提交和下载均为演示。

## 安装

最新安装包：`artifacts/Canvas-Suixing-0.3.0-ai-arm64.apk`，适用于 ARM64 安卓手机和平板。校验值见同目录 `SHA256SUMS-0.3.0.txt`。保持相同开发签名，可覆盖安装 0.1.0 / 0.1.1 / 0.2.0。

将 APK 传到设备，点击文件并按系统安装提示操作。此包使用开发调试签名，正式版签名尚未交付；后续换签名可能需要卸载重装。

应用内使用真实数据入口，未连接账号时显示空状态，不会显示 Demo 的示例课程。

## 已验证

- 前端构建、40 项逻辑测试、Windows 中文 UTF-8 回归通过。
- 浏览器手机与多种平板宽度检查通过，无横向溢出。
- ARM64 与 x86_64 调试 APK 构建通过；ARM64 APK 签名验证通过，最低 API 29。
- Android 10 模拟器安装与冷启动通过，并检查手机和大平板窗口的界面。截图位于 `docs/screenshots/`。

## 尚待完成

此版还不是稳定自用版。真实 Token 已通过官方接口与 Android 模拟器验证，课程查询、扫码二维码获取／保存、未确认扫码的负向检查及断网提示已验证。新增的双认证、同机扫码操作与网络自检见 `AUTH_ACCEPTANCE.md`。

用户手机原有的连接失败尚未在模拟器中复现。如果新包仍连接失败，请在“我的 → 连接账号”中运行“网络自检”，结合新的具体错误继续定位。真实作业提交、微信确认后的完整录播／云盘认证、视频、真实模型服务、通知和后台下载等仍待验收；物理手机、物理平板和较新 Android 的验收也未完成。

0.3.0 已增加模型列表、连接测试、流式问答、课件提取、公式与夜间模式，使用本机模拟模型服务验证了 Android 原生链路，详见 `AI_AND_APPEARANCE_0.3.0.md`。云盘上传界面、多组已保存模型配置、版本更新入口及部分账号／生命周期处理仍需补齐。完整状态见 `ANDROID_IMPLEMENTATION.md`。
