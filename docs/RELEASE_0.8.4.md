# Canvas 随行 0.8.4 · Android 开发预览

日期：2026-10-18。Android 手机／平板版本，Android 10+，仅 ARM64。基于上游 SJTU-Canvas-Helper 3.0.13，保留 MIT 许可及 GitHub fork 历史；本版本不修改或发布上游 Windows／桌面版。

## 本次变化

- 学习空间：按可用宽高响应的单双栏、资料正文／字幕／笔记搜索、时间轴笔记、可编辑本机日程、作业要求及附件操作、提交成功庆祝动画。
- 文件阅读：统一通过 Canvas 平台预览，页面内小框与独立阅读页；已下载文件优先平台预览，连接超时或不可用时回退外部应用。没有内置 Office 排版或转换引擎。
- AI 学习：预设提示词、追问建议、选中文字追问、截图标记及字幕时间上下文、对话提炼为笔记、回复完成提醒；课堂与文件对话均可在主助手历史中继续。
- 对话界面：紧凑单行操作、图标展开、输入框原地变大及手动收起、发送固定右侧、直接发送建议、Enter 发送／Shift+Enter 换行；发出的图片不再占据输入区。
- 录播：全屏保留工具及字幕开关、长按加速、课件切片紧凑小窗、主次互换、位置和缩放边界调整。
- 会话恢复：恢复绑定当前账号的已验证官方网页会话，分别处理认证、权限与网络错误，避免所有错误都要求重新登录。
- 外观：折带图标、设置页、继续问按钮、连续水面与玻璃光影；水面主入口不再使用粒子轮廓渲染。

## 已完成的检查

- 前端 54 个测试文件、202 项测试通过，类型检查、生产构建与严格 UTF-8／中文 JSON 往返检查通过。
- Android ARM64 APK 构建、14 项 Android 单元测试通过。
- Rust 核心 12 项测试通过，涵盖文件文字提取、上下文、流式分包及终止状态。
- 浏览器检查输入框、设置与继续问控件，覆盖手机、宽屏及较矮视口；这些不等同于真机视觉验收。
- 安装包校验包名、版本、ABI、签名和内嵌资源一致性；公开源码另行检查凭据、私钥、编码和本机文件边界。

## 验证边界

本轮未连接物理设备，尚未验证真实学校登录的长期恢复、平台复杂课件预览、全屏小窗的实际手感、设备传感器、长时间耗电与外部阅读器联动；因此标记为 prerelease。学校预览服务、权限与网络会影响文件可用性，外部打开需要系统存在兼容阅读器。

AI 使用自行配置的模型服务；是否接受图片、上下文容量及费用取决于服务商。不包含此前试验的 ChatGPT 网页集成。没有代替用户提交真实作业进行测试，庆祝动画只在服务返回提交成功后触发。

账号凭据、模型密钥、私人课程原文、本机诊断资料和签名私钥不随源码或 Release 上传。
