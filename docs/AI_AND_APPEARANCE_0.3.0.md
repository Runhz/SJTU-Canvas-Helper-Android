# 0.3.0：课件、AI 与外观

## 使用变化

课程元数据定时刷新时保留已加载的资料列表。进入课程仍会按需拉取资料；“刷新列表”重新获取服务器目录，失败时保留上次列表并显示错误。切换账号后不接收旧账号的延迟结果。

AI 支持 PPT、PPTX/PPTM、PDF、DOCX、XLSX/XLSM、OpenDocument 与常见文本/代码格式。PPTX 按演示顺序读取幻灯片并跟随关系表提取备注；旧版 PPT 按当前编辑版本的对象索引读取，备注单独编号，避免混入已经删除的历史页面。格式提取不需要 Office、FFmpeg 或 PDF 转换。

文件读取默认上限 128 MB，可在“我的 → AI 服务配置”选择 32/64/128/256 MB。文件按账号、文件 ID、版本和读取器版本缓存；每次询问会检查服务器元数据，同一版本不会重复下载或提取。缓存只在本机，普通下载单独保存。

原来固定的 10 万字符拒绝条件已从移动问答链路移除。单次模型资料上下文可选 1.6 万至 51.2 万字符。长资料有两种方式：

- 快速问答：完整提取文件后，选择相关片段；概要类问题均匀抽样。实际覆盖范围会发给模型，不能声称是完整全文总结。
- 全文分段：先覆盖所有文字分段提取重点，再生成最终回答；会进行多次模型调用，界面显示处理进度。

回答通过流式通道边接收边显示，可停止生成。Markdown、表格、代码、`$...$` / `$$...$$` / `\(...\)` / `\[...\]` 公式统一排版。Android 10 的旧 WebView 提供必要的 `Object.hasOwn` 兼容层。

AI 设置支持从填写的兼容服务获取模型列表、搜索、选择、手动填写模型名和测试流式连接。列表仅代表服务返回的可见模型，不自动推断模型上下文大小或视觉能力。

“我的”增加日间、夜间和跟随系统，外观选择保存在本机。应用内部与安卓启动图标统一使用书页与书签图形，支持 Android 自适应图标及 Android 13 单色图标。

## 验证（2026-10-15）

- 前端：40 项测试，通过；覆盖资料保留、刷新失败、回答未结束时显示首段、停止生成、部分回答保留、公式、模型筛选与配置保存等。
- Rust 核心：9 项测试，通过；覆盖 PPT 当前版本、PPTX 页面顺序/真实备注关联、XLSX、乱码/损坏、上下文选择、SSE 中文字节边界与真实 HTTP 首段提前交付。
- 回归样本：超过 25 MB 的 PPTX 与超过 10 万字符的正文可提取。
- Apache POI 的真实格式样本提取通过：`basic_test_ppt_file.ppt`（2 页）、`testPPT.pptx`（3 页）。样本仅在 D 盘测试工具目录保存，来自 `apache/poi` 仓库的 `test-data/slideshow`，不打包进 APK。
- Android 10 / Chromium 74：夜间模式、模型列表、原生网络 → Rust → 前端的分段回调、行内公式和积分公式通过。使用本机模拟模型接口，无外部模型费用、无真实 Canvas 凭据。
- 模拟接口计时：首段在约 162 ms 出现在实际安卓界面，后续内容持续追加，约 3498 ms 标记完成。这是流式链路证据，不代表真实模型的响应速度。
- 中文配置严格 UTF-8 回读通过；前端依赖审计为 0 项漏洞。

## 实际边界

- 扫描 PDF、纯图片 PPT、图中的公式/图表不能靠文本提取得到，仍需先提供 OCR 文字；本版未增加手机端 OCR 模型。
- 加密或损坏课件会明确失败；没有承诺所有旧 Office 二进制格式，例如 DOC/XLS。
- 提高上限会增加手机内存与模型上下文占用；长资料全文分段会增加耗时及模型调用次数。
- 文件元数据鉴权、用户自己的课件与模型供应商仍需真机验收。已验证格式样本与本机兼容接口，不把模拟模型回答当作真实课程问答验收。

安装包与 SHA-256 位于 `artifacts/Canvas-Suixing-0.3.0-ai-arm64.apk` 和 `artifacts/SHA256SUMS-0.3.0.txt`。

最终 ARM64 包签名校验通过：包名 `com.canvas.sjtu.mobile`，版本 `0.3.0` / `3000`，最低 API 29，目标 API 36，与已交付版本的开发签名一致。最终 x86_64 包覆盖安装、清除测试数据后冷启动通过（1131 ms）；初始页为未连接账号的空状态，无真实凭据或示例课程。测试模型配置已清除。
