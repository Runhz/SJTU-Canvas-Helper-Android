# 稳定版本验收表

每次验收记录版本、日期、设备／系统、步骤、实际结果和证据。预览版不等于稳定版本。

当前 0.5.4 增加页面与录播状态恢复、按账号保存的 AI 历史与草稿，见 [RELEASE_0.5.4.md](RELEASE_0.5.4.md)。95 项前端测试、前端构建及 ARM64 APK 构建／签名检查通过；手机与 Pad 浏览器验证真实 IndexedDB 保存、重载恢复及历史搜索，未连接安卓真机，实际设备生命周期仍待验证。

当前 0.5.3 已打入原生视频弹窗遮挡修复并构建 ARM64 APK，验证细节与校验值见 [RELEASE_0.5.3.md](RELEASE_0.5.3.md)。前端 81 项、Rust 核心 10 项及 APK 构建／签名核对通过；实际手机与 Pad 的安装、遮挡及旋转待验证。

当前 0.5.2 已将用户确认的连续水面集成主应用并构建 ARM64 APK，见 [RELEASE_0.5.2.md](RELEASE_0.5.2.md)。前端 76 项、Rust 核心 10 项及构建检查通过；手机／Pad 浏览器预览通过。本轮没有连接安卓设备，实际安装升级及传感器体验待验证。水面实现记录见 [WATER_FLUID.md](WATER_FLUID.md)。

2026-10-15 后续修复（已随 0.5.3 打包）：用户提供 Pad 截图，原生视频覆盖“提问资料”选择弹窗。原因是播放器附加在安卓窗口的 WebView 上方，独立选择弹窗未参与既有播放器遮挡状态。现在全部 Modal 在显示前统一通知原生层隐藏并暂停视频，最后一个弹窗关闭后恢复原位置，播放由用户继续。原生遮挡状态独立于播放器创建和位置更新保存，防止延迟打开、滚动或尺寸回调重新显示视频。新增嵌套弹窗、StrictMode、393／768 宽度的课堂选择回归；共 81 项前端测试、前端类型检查／生产构建、UTF-8 检查及 ARM64 Kotlin 编译通过。ADB 未检测到设备，实际手机／Pad 遮挡与旋转待验。

已打包 0.5.1 的手机布局、旧水缸与 ARM64 构建结果见 [RELEASE_0.5.1.md](RELEASE_0.5.1.md)。该版尚未进行用户手机安装验收，不覆盖此前真实服务与设备生命周期待办。

0.5.0 的本轮结果见 [RELEASE_0.5.0.md](RELEASE_0.5.0.md)。新增缓存、三档水缸画质、选择面板、字幕范围、日程过滤已自动验证；原生视频公开样本与本机模型模拟服务已联调。GLES 3 真机图形、学校数据和实际模型仍待验收，不能用模拟器降级或模拟服务替代。
