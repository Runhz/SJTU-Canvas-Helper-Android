# Canvas 随行 0.8.7 · Android 开发预览

日期：2026-10-19。Android 10+，仅 ARM64。独立维护 Android fork，保留上游 SJTU-Canvas-Helper 3.0.13 的 MIT 许可与历史；不修改或发布上游 Windows／桌面版。

## 变化

- 修复附件已经准备好，但模型只收到字幕的问题。文件正文经过实际解析后进入请求，显示读取范围；复用本机已下载资料。
- PDF 按页渲染图片交给视觉模型，不引入 OCR。文字型 PDF 默认提供首页图像，扫描 PDF 默认提供前三页；可问“解释第 9 页”或“比较第 9—10 页”按需提供指定页，每个文件单次最多 3 页。其他页面不会被描述成已看过。
- DOCX 正文及表格使用 OpenXML 解析；现有 PPT/PPTX、XLSX 等文字读取继续保留。复杂图表通过页面截图或课件切片提问，不内置完整 Office 引擎。
- 阅读、课件、表格、代码、推导、讲解和笔记技能按实际资料和问题启用；系统身份与资料数据分离，按模型与用户配置限制上下文，按完整轮次裁剪历史。
- 模型服务返回的思考文本或摘要单独流式展示，默认收起、点击展开、随对话保存；不显示加密载荷，不把思考内容重新作为回答发送。服务不提供可展示内容时不伪造。
- 透明玻璃立方体与 GPU 水面，支持触摸、倾斜及左右、前后、上下摇晃。返回主页复用最近真实画面，减少简略占位闪烁；离页释放 GPU。仍是高度场效果，不是可倒置的三维体积流体。
- 汇总此前本地优化：字幕选择提问、课件切片滚动与固定横向、头像裁切、笔记阅读与公式适配、作业全部完成总结动画和界面改进。

## 检查与边界

- 65 个前端测试文件、232 项测试通过；生产类型检查及构建通过；177 份源文件编码与中文 JSON 往返检查通过。
- 20 项 Rust 核心测试通过，包含真实两页测试 PDF 的提取、DOCX/PPTX/旧 PPT/XLSX、本地 HTTP 请求中实际资料正文，以及思考与回答分流。
- 14 项 Android 单元测试通过；ARM64 Rust/Kotlin/Gradle 构建完成。
- 浏览器检查实际对话界面的思考折叠与展开、393px 窄屏布局；检查 GPU 水面、合成竖直加速度事件及页面切换。合成事件不等于真机传感器体验。
- APK 包名、版本、ABI、签名、30 份图标资源、内嵌前端和本机库一致性已检查，测试页面未打入安装包。
- 单次最多 6 个文件，资料文字总量上限 200 万字符，送入模型时再按容量缩减；单次最多 7 张图片。PDF 看图需要视觉模型，明确不支持时会提示切换。细密小字或公式可能需要局部截图。
- 本轮未连接物理设备，未使用真实学校账号、私有课件或真实模型服务端到端验收，因此发布为 prerelease。本地 HTTP 测试不能证明模型理解效果。
