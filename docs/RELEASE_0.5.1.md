# 0.5.1 移动端修订记录

2026-10-15。包名 `com.canvas.sjtu.mobile`，版本 0.5.1／5001，Android 10+，ARM64，沿用此前开发签名。

## 本轮变化

- 顶部去掉品牌行，改为搜索框和通知；保留原有全局搜索。
- 手机课程与录播课程采用双列紧凑卡片，长标题完整换行。管理入口显示文字与滑杆图标，保留长按。
- 手机底部采用圆角导航，无顶部分隔线；选中态集中在图标。Pad 保留侧边导航。
- 水缸取消 24° 倾斜限制，原生返回完整屏幕重力向量与摇晃峰值，每 50 毫秒读取，逐帧插值。倒置、前后倾斜、跨 ±π 角度与回稳使用同一套惯性模型。
- 省电为 96×96 像素水粒，均衡为柔光水面；两者使用 Canvas 2D。高清使用 Three.js 玻璃及柔和环境反射，去掉旧房间反射中的方块。效果均随重力和晃动响应；属于视觉模拟，不是流体力学求解器。
- 水缸移除触摸高亮和文字选中，其他按钮保留键盘焦点。

## 验证

- 18 个测试文件、66 项通过。新增倒置、快速响应、前后倾斜、角度跨界、晃动回稳、帧率一致性及减少动态效果检查。
- 前端类型检查与生产构建通过；严格 UTF-8、中文配置写入回读、58 个前端源码文件检查通过。
- 浏览器实际验证 pixel／soft／glass 三种渲染器，省电与均衡分别使用 96／320 像素画布；高清实际渲染，无控制台错误。
- 320／393 手机、768 Pad 的课程布局无横向溢出。393 宽度录播卡片两列，普通卡片约 132 像素高，长标题一行约 149 像素高。截图均为示例数据。
- ARM64 Kotlin／Rust／Gradle 构建通过。APK 内原生库匹配本次构建，包含最新界面与水缸资源。签名验证通过，证书与上一版相同；版本码递增至 5001。
- 本轮未构建 x86 APK，也未导出源码副本或压缩包。旧版本的 33 项交付产物、构建目录中的旧 x86 APK 已移入回收站；旧测试证据移到忽略的 local-diagnostics。

## 交付与边界

`artifacts` 仅保留 `Canvas-Suixing-latest.apk` 和 `SHA256SUMS.txt`。后续默认只更新工作项目，需要安装包时再生成 ARM64，覆盖这一位置；不在每次修改后自动打包或导出源码。保留完整工作仓库和 D 盘工具链。

这版尚未在用户手机安装验收。真实晃动灵敏度、设备旋转后的重力映射、GPU 画质、帧率、耗电和触摸高亮仍需真机核对；浏览器与合成测试不能替代这些结果。0.5.0 记录中的学校服务与模型验收、Android 10 显示参数变化时的渲染崩溃待办继续保留。
