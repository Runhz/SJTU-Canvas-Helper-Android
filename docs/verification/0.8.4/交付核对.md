# Canvas 随行 0.8.4 个人版交付核对

日期：2026-10-18。仅本地交付 ARM64 APK，未提交或上传 GitHub。

## 本轮逐项更正

| 用户指出的问题 | 当前实现 | 已完成的核对 |
| --- | --- | --- |
| 输入框不平衡，“扩大”文字按钮过大 | 文字输入区、扩大图标、发送按钮同一行；扩大仅保留图标；发送固定在最右侧；原地展开和手动收起 | 浏览器检查三种尺寸下的按钮中心线、右边界及展开高度；直接发送建议问题测试通过 |
| 不需要单独“采用” | 建议显示在输入框占位中，直接发送即提交建议；点进输入框可直接编辑；没有额外采用按钮 | 真实 AiChat 组件测试直接提交建议，确认实际发送问题一致 |
| 课件小窗工具占面积过大 | 原生切片小窗只保留底部一条 30 dp 控制栏；隐藏重复的标题栏和缩放栏；拖动握柄、互换和截图提问保留；右下角缩放手柄缩为 22 dp；全屏外层模式栏由 42 dp 收紧为 32 dp | 原生代码编译通过，APK DEX 中确认新版布局已包含，旧“课件 · 拖动移动”说明字符串已移除；尚无真机视觉验收 |
| 小窗总恢复成旧的大尺寸 | 小窗使用新的布局偏好版本，初始高度按课件比例和紧凑工具栏计算，避免恢复旧版过高的默认值；保留边界约束 | Android 几何测试通过；需设备验证横竖屏与拖动手感 |
| “继续问”只有文字 | 改为圆角描边按钮，使用浅色强调底和向右上图标 | 使用实际 LectureQuestions 组件及本地测试对话核对：按钮 82 × 36 CSS px，圆角 11 px、边框 1 px；点击携带原对话 ID |
| 明明登录，重开又提示过期 | 不再在同一账号打开官方验证时无条件清空网页 Cookie；恢复经过本应用确认、绑定当前账号的官方网页会话到原生请求端；保留更新后的身份凭据 | 会话恢复顺序及缺失网页会话时保留 Token 访问的测试通过；真实学校账号联网验证尚未完成 |
| 网络或权限错误也要求重新登录 | 401、403 和网络失败分开显示；非认证错误提供重新加载，不强制进入登录；重新加载当前课堂时保留所选课堂 | 前端测试、原生编译通过；真实服务错误场景待设备测试 |
| 下载文件要能删除、能预览 | 完成、失败、取消等下载均可删除；Canvas 文件先取官方预览，取不到时打开已下载原件；获取预览超过 8 秒也回退；官方阅读页主页面加载失败时也可打开原件，页面保留“外部打开”按钮 | 平台预览、外部回退、视频直接打开和删除测试通过；外部阅读器联动尚未真机验收 |
| 设置页过于松散 | 收紧卡片与控件间距、统一圆角和按钮边框，宽屏设置入口改为两列 | 浏览器截图检查，1200 px 视口下两列实测均为 454 px |
| 水面仍然颗粒结团、容易破洞 | 主界面实际切换到连续水面渲染，保留第三版透光水晶方向；水量、重力方向、衰减波动及玻璃反射分开处理；不再加载原粒子模拟和 Three.js 水面块 | 浏览器确认实际渲染器为 crystal-surface，拖动后连续水面保持完整；最终前端产物不存在 WaterScene 块；未测物理设备传感器和帧率 |
| 作业成功庆祝 | 保留已选择的第三版小型烟花；仅提交成功后触发 | 提交主流程回归测试通过；本轮没有提交任何真实作业 |

## 核对范围

- 前端：54 个测试文件、202 项测试通过；类型检查与生产构建通过。
- Android：ARM64 调试安装包构建通过，14 项 Android 单元测试通过。
- 编码：149 个前端源文件严格 UTF-8、无 BOM、中文 JSON 往返与界面字串检查通过。
- 安装包：包名 com.canvas.sjtu.mobile，版本 0.8.4，版本号 8004，仅含 arm64-v8a；签名验证通过，与上一轮签名一致。
- 包内资源：封装的原生库与最终构建文件完全一致，最终前端块全部存在；新输入框、连续水面、继续问按钮、原生小窗 v3 和会话恢复代码均已包含。
- 浏览器视口：1200 × 800、393 × 852、560 × 320。输入行高分别为 38、38、36 CSS px；扩大与发送按钮的中心线一致，右侧不溢出。1200 × 800 下输入区原地展开到 208 CSS px，随后收起到 38 CSS px。
- 当前 ADB 未连接任何设备。因此，没有把浏览器或单元测试称作真机验收；学校账号、真实课程预览、Android 外部阅读器以及原生全屏课件小窗仍待安装测试。
