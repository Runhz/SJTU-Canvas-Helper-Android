# 对话与资料边界检查：第三轮

2026-10-19。接续前两轮本地修复；本轮没有修改版本号、打包 APK、提交或上传 GitHub。现有 0.8.7 APK 尚未包含这三轮源码修复。

## 实际复现与修复

修改生产代码前，新增 8 项回归测试，全部失败；其中 3 项针对资料入口、3 项针对对话切换，2 项针对录播问题回看。修复后全部通过。

| 场景 | 原问题 | 修复 |
| --- | --- | --- |
| 资料面板尚未关闭，又从另一处打开助手 | 共用的可变回调被新入口覆盖，甲资料交给乙入口 | 每次资料选择固定自己的回调；普通助手入口不改写正在选择的资料 |
| 连续从两个地方打开资料面板 | 标题和回调更新，面板选中的内容仍是上一处 | 每次选择使用新的实例；失效实例的确认和关闭回调不再生效 |
| 资料选择时切换账号 | 旧面板可能留在新账号界面 | 按账号限制面板显示和确认；切换时卸载旧面板并阻止旧结果回流 |
| 对话甲的资料读取尚未确认，已切到对话乙 | 确认后直接更新当前对话，乙被改成甲资料 | 确认必须仍属于原对话及原入口；否则保留乙内容并提示未更改资料 |
| 截图编辑时切换课堂 | 编辑窗口沿用旧状态，可能把旧标记应用到新图 | 切入口和选历史对话时关闭截图编辑 |
| 笔记提炼时切换对话 | 提炼内容来自甲，保存时标题和来源可能已变成乙 | 切换时关闭提炼界面并取消请求；笔记组件按对话 ID 区分 |
| 回看开头 00:00 的问题 | 零被当作无值，实际跳到当前播放位置 | 单独检查时间是否有效，允许回到第 0 毫秒 |
| 从其他地方删除课堂对话 | 录播页仍显示被删除问题及继续问按钮 | 按账号响应删除，移除旧显示，重新取本堂较早的有效对话；没有则隐藏 |

录播问题入口另按问题自身的资料类型打开，不再把当前对话类型强加到旧问题上。切换课堂时清空旧问题显示；异步读取使用序号和卸载检查，旧列表不会覆盖新列表。
