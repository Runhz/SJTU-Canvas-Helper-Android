# 对话 PDF 读取结果复用修复

日期：2026-10-19。基于公开 0.8.7 后的本地源码修改，本轮未打包 APK、未提交或发布到 GitHub。现有 0.8.7 APK 不包含本次修复。

## 原因与修改

1. AiChat 从课件入口恢复对话时，用仅含文件标识的入口 payload 整体覆盖了已保存的资料正文和页图像。现在按同一账号对话中的文件 ID、课程及版本合并；不再丢失已读取内容。
2. 历史问题为减少存储只保留文件引用。恢复旧问题、引用旧回答和“太难了”等反馈入口现在都先从对话中恢复匹配的读取结果，避免再次下载和解析。
3. 准备好资料但尚未输入问题时关闭窗口，原先保存条件会跳过这个对话。现在已准备的正文也触发保存。
4. 保存文件更新时间、大小和读取版本。入口出现新版本时丢弃旧正文与失效的下载引用，重新读取；不复活已经取消选择的附件。
5. 历史问题保留轻量页码引用；正文仍只保留一份。旧问题引用的页与当前页不同时，只补充必要页图像，不重新解析整个文件。明确指定新页码优先于旧页码记录，课件换版后不沿用失效页码。

## 验证

- 完整前端测试 239 项通过，失败 0。报告：`local-diagnostics/tests-document-reuse.json`。
- 新增 AiChat 结合 IndexedDB 的集成回归测试：首次解析后关闭窗口、清除运行中的会话状态并重新挂载，后续提问仍收到已保存的正文与图片；准备、解析和默认页渲染调用计数均保持首次一次。
- 覆盖尚未提问即关闭、旧问题入口、回答反馈继续问、明确页码与默认页码衔接、账号身份切换、课件换版及移除附件。
- 首次测试出现多处“太难了”按钮导致定位歧义，已将测试限定到目标回答的操作区；修正后通过。
- 类型检查与生产构建通过；178 份源文件编码/中文 JSON 往返检查、公开源码基本凭据扫描通过。
- 最后补充“新版本清除旧页码”边界后，相关 17 项回归测试及类型检查/生产构建再次通过。

自动测试中的文件解析、模型服务与 Android 页面渲染接口为受控替身；这证明应用的缓存恢复及请求资料传递，不代表真实课件、真机或真实模型服务的本轮验收。

## 使用边界

缓存保存在本机对话记录，正常关闭窗口或重开应用后复用。用户删除对话、清除应用数据或取消附件后，不承诺继续保留该附件的读取结果。需要未缓存的页面时仍需原文件；资料换版或旧记录缺少可验证的版本信息时可能重新读取一次。

本次没有建立模型服务器上的永久文件存储。每次问答仍根据上下文预算提供所需资料，模型可读范围与 0.8.7 的 PDF 看图限制一致。“全文总结”中的模型分段压缩处理也未在本轮增加结果缓存。
