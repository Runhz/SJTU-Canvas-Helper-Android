# AI 学习工作流、技能选择与上下文管理

2026-10-19。本轮修改本地源码；没有改版本、重新交付 APK 或上传 GitHub。此前交付的 0.8.8 APK 不包含本轮教学技能与上下文改动。

## 研究与取舍

目标是减少学生看课时反复选择资料、重复交代背景的操作，并提供可选择、可预览的教学方式。没有一种提示模板能保证对所有学生、所有阶段都最好。本轮将已有教学研究转化为明确的交互行为，未把这些策略当成经过验证的本应用学习效果。

- [IES / WWC 学习与记忆实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：参考主动检索、例题与练习交替、具体与抽象表征联系、解释性提问。落实为主动回忆、例题带练、对比迁移与自我解释。
- [EEF 元认知与自我调节指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition)：参考示范、支架和逐步独立。落实为先给最小有用帮助，卡住时增加支架，已经会的内容不重复讲。
- [EEF 反馈指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/feedback)：参考针对具体任务、可采取行动的反馈。落实为检查学生说法的条件和因果缺口，提供修正机会，不凭“懂了”宣称掌握。
- [OpenAI 官方提示工程文档](https://developers.openai.com/api/docs/guides/prompt-engineering)与[推理模型提示建议](https://developers.openai.com/api/docs/guides/reasoning-best-practices)：参考清晰角色、分离规则和资料、简洁明确的任务说明。没有强制索要内部思考或制造假思考。
- 检查了现有 [benrosche/socratic-tutor](https://github.com/benrosche/socratic-tutor/blob/master/templates/lab-repo/.posit/assistant/skills/tutor/SKILL.md) 和 [bstellato/ai-teaching-skills](https://github.com/bstellato/ai-teaching-skills)。没有安装它们、复用其服务器或照搬源码；其持续限制最终答案的设定不适合个人学习应用。这里允许用户要求直接解释、完整答案或结束测验。

EEF 指南主要面向学校教学，不能直接推断到大学生使用特定模型的效果。IES 的教学策略也不是本应用的模型质量测试。

## 已实现的学习流程

1. 普通录播提问仍保留当前已播放约 150 秒内的字幕作为重点，同时将该堂已加载的全部字幕作为背景。背景与重点分开，注明当前位置；背景可能包含未播放内容，不假定学生已经学过。
2. 同一课堂之前由用户选中的课件，在下一次截图提问时继续带上，并复用版本匹配的正文缓存。切到另一堂课不沿用；不擅自选择全课程文件或声称已把 PPT 页与教师画面准确匹配。
3. 当前字幕、课件参考、整堂字幕参考、符号备忘和真正发送的图片页码分别提供。文字总量受当前额度约束；过长背景使用本机关键词片段选择，当前片段保留优先级。没有增加向量数据库、额外模型路由调用或后台解析任务。
4. “仅所选字幕”和“不附字幕”会排除整堂背景；资料面板改时间范围或取消字幕也会排除，前端和原生请求两层检查。
5. 全堂总结启用全文分段处理。多文件全文处理在摘要前保留各文件全文，不先按每份文件抽样。分段压缩结果和原始文字选段分开标明，不能称为完整原文或全部图表。
6. 整堂背景和课件正文只保留在当前对话资料中，历史问题定位保留引用，避免每问一轮重复保存整堂字幕。恢复旧问题时只从同一课堂恢复背景。

## Skill 按钮与预览

助手工具栏新增独立 Skill 按钮。默认自动选择，可手动固定为：启发式提示、检查我的理解、主动回忆、我来讲你来查、例题带练、公式推导、对比与迁移、补前置知识、总结与复习、直接讲清楚。

- 每项有用途、提问示例、实际注入的教学提示词和教学依据；通用教学与资料规则也能展开查看。
- 前端预览与原生注入共用 `demo/src/learningSkills.json`；通用系统规则共用 `demo/src/learningBase.md`。
- 自动选择依据本轮问题的明确词语；模型仍需结合近期对话理解学生正在回答什么。这不是经过评测的语义分类器。
- 手动选择随这段对话保存；切换不清空草稿、历史或已选资料，也不自动发送问题。切换到其他对话关闭旧面板。
- PDF、课件、表格、代码等资料规则按文件类型自动加入，不要求用户再选一次文件类型 skill。
- 系统规则要求先理解问题、核对来源、按需要讲解、对学生回答反馈；尊重其直接要答案或停止测验的要求，不无限反问、不每轮强制考试、不把历史模型回答当作原文证据。

## 同时修复的上下文问题

- 将一般助手类型中的实际附件送往资料问答流程，避免带了正文却进入只查询课程目录的分支。
- 一般助手向模型传递结构化 user / assistant 历史，而非拼成一段带角色名称的普通文字。
- 从刚准备完成的 PDF / PPT 正文核对符号定义；整堂字幕背景里的原始定义也可参与核对。
- 避免空文件数组误清除“仅所选字幕”的正文。
- 选中从 00:00 开始的字幕时，使用真实的零时间，不错误退回当前播放位置。
- 明确图片是否真正发送、文件阅读范围和历史省略，避免只读了文字却假装看过图表。
