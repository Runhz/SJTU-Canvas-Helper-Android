## 两轮检查与额外边界检查

第一轮：使用实际组件，在 393×852、1024×768、560×320 视口核对字幕、课件、笔记，检查横向溢出和弹窗边界；检查平板设置两列布局。发现并修正设置列宽、全屏组件样式加载和非交互容器焦点边框。

第二轮：核对选字幕后退出选择再提问、清空选择、课件翻页与全屏往返、笔记导出、头像裁切保存与重载、最后一项作业完成及减少动态效果。发现并修正清空后操作栏消失、全屏快速翻页状态、缺省学期过滤和自由提问逻辑。

追加边界轮：检查 280×480、320×480、1280×320 下的字幕、课件、笔记及长行内公式，共 12 组布局；另检查 240×480 头像裁切、全屏中切换横竖视口、动画中按 Escape 关闭。

本轮实际修复的边界问题：

- 极窄窗口头像裁切区域变形、按钮横向溢出：裁切按实际宽度计算，网格允许收缩，操作区自适应。
- 超长中文和表情笔记标题超过文件名长度：按 UTF-8 字节限制并去除非法字符，避免截断 Unicode 字符。
- 课件图片网络卡住时一直空白：增加加载提示、18 秒超时、失败重试和卸载清理；空课件不再显示无效页码。
- 原生课件尚在加载时截图提问：阻止截取加载占位画面，提示待画面加载后重试。
- 隐藏的切片 OCR 搜索入口：移除并回归确认不会误删笔记。

全屏视口变化后提问仍指向原页；动画关闭后确认庆祝画布数量为 0、没有残留 inert 标记或 body 滚动锁。图片超时、重试、完成加载后的定时器与卸载清理均有自动测试。

## 验证结果与限制

- 前端：60 个测试文件、215 项测试通过；类型检查和生产构建通过。
- Android：最终 ARM64 安装包构建成功；14 项原生单元测试通过。
- UTF-8：161 个前端源文件、中文 JSON 往返、无 BOM 和关键 UI 字串检查通过；公开源码基本凭据与编码检查通过，未进行完整 Git 历史审计。
- 浏览器：实际组件交互验证及截图检查；演示资料没有向真实 AI 服务发送请求，没有提交真实作业。临时测试挂载已删除，不随安装包交付。
- 当前 ADB 无连接设备。没有把浏览器检查称为 Android 真机验收：校园登录、真实平台课件预览、原生视频手势、设备传感器和长期性能仍需要安装后验证。
- jsdom 测试环境中的旧庆祝组件会输出 Canvas 未实现提示；测试断言通过，实际动画另在浏览器运行核对。
- Windows 原生库符号链接权限不足时，现有构建脚本使用复制原生库的回退流程；最终 Gradle 构建成功，并比对包内库一致。

庆祝粒子采用按需加载的 [canvas-confetti](https://github.com/catdad/canvas-confetti)，仅在完成事件时运行，保留 ISC 许可；关闭时清理，减少动态效果模式不播放粒子。没有为水球引入新的三维运行引擎。
