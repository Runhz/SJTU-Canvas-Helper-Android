# 水缸重做

本轮仅调整水缸，保留现有页面布局。取消像素材质，三个画质档采用同一种连续液体，区别为模拟分辨率、压力求解次数和渲染分辨率。

1. 采用 mobile-fluid-sim 的 MIT FLIP 求解器（固定提交 `52eca767d1d81b166ed8a930a8ffd67b7d14fb73`），保留原始代码及许可。它参考 Ten Minute Physics 的 FLIP 教程。
2. 新增圆形容器边界、固定时间步、重力和惯性力输入；自由液面、撞壁、液滴分离及回落由粒子运动产生，不再旋转整块水体。
3. 新建屏幕空间液面渲染，将密集粒子重建为连续水体，保留独立液滴；叠加透射、厚度着色、曲面反光和透明缸壁。属于二维流体与立体光学表现，并非完整三维流体。
4. 省电、均衡、高清均取消像素风；无 WebGL 时使用相同模拟的 Canvas 渲染。离屏、后台暂停，尊重系统减少动态效果设置。
5. 验证静水、倒置、摇晃、液滴、边界、数值稳定、不同帧率、作业数量变化和生命周期；检查手机及 Pad 预览，运行类型、构建及测试。

本轮默认不生成 APK 或源码压缩包。手机实际传感器体验仍需真机确认。
