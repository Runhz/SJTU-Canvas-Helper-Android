# 0.2.0 交互更新

- 总览、课程、提醒消息和录播页共用学期筛选，默认本学期；可切换到服务端返回的其他学期或所有学期。
- 作业与课程支持长按或 `···` 菜单：忽略作业、移除本机列表、恢复显示；忽略和移除都会停止该项的后续提醒。
- 录播页加入内嵌 Media3 播放器，支持机位切换、倍速、双机位、横屏全屏、位置保存和离开页面暂停。
- 字幕支持导出 SRT 和文字稿；字幕与 OCR 资料可用于本堂课总结和连续提问。
- AI 对话进入录播页，时间引用只允许跳转到当前课堂资料实际提供的时间点。
- 后台提醒重新使用当前筛选和本机忽略记录，已提交作业仍会自动取消后续提醒。

真机上的真实录播地址、双机位硬件解码和模型服务仍需使用真实账号验证；模拟器只验证界面、播放器生命周期和构建链路。
