# Canvas 随行 0.8.9 · 学习 Skill 与持续资料上下文

日期：2026-10-19。Android 10+，仅 ARM64，开发签名预览。Android 分支保留上游 MIT 许可与历史，不修改或发布上游 Windows／桌面版。

## 本次变化

- AI 工具栏增加 Skill 按钮，可选择并预览 10 种教学方式：启发式提示、检查理解、主动回忆、学生复述、例题带练、逐步推导、概念对比、补先修知识、整理笔记、直接讲解。默认按问题关键词自动选择；手动选择随对话保存，只影响后续回答。
- 界面与模型共用同一份技能目录和通用系统规则；资料类型阅读规则与教学方式分别管理。先处理当前疑问，再按需补充背景；学生明确要求答案时直接回应，不强制每轮测验或无限反问。
- 当前播放位置附近的字幕作为重点，整堂已加载字幕作为背景，按问题与容量选取相关内容；显式选择字幕或关闭字幕资料时不夹带全课字幕。全部字幕不代表每次全部原样送入模型。
- 同一课堂继续截图提问时保留手动选择的课件。已解析正文与 PDF 页面资料按账号、对话与文件版本保存，重新进入对话可以复用；变更文件版本或需要新页面时重新准备。
- 修复旧资料异步结果覆盖新对话、快速切换时草稿丢失、删除后旧任务恢复对话、取消截图后图片被重新附上等边界问题；保留字幕、文件及历史轮次的来源范围。
- 原生请求区分当前上下文、课件正文、全课字幕与实际图片页，控制各部分预算；通用助手使用结构化对话历史。预览中的通用规则与原生实际注入规则保持一致。

## 验证与限制

- 271 项前端测试、30 项 Rust 核心测试、14 项 Android 单元测试通过；TypeScript、Vite 与 ARM64 Rust／Gradle 构建完成。
- 188 份前端源文件编码、中文 JSON 写入与读回检查通过；公开源码边界与基础凭据扫描通过。
- 浏览器检查 Skill 选择、提示词及通用规则预览、应用后保留草稿，以及 320px 手机、横屏、平板与低高度窗口边界。测试未调用真实模型服务。
- APK 已检查包名、版本、最低系统、ARM64 架构、证书、前端资源与原生库一致性，30 份图标资源与 0.8.8 一致，未打包测试页面或 Office 引擎。

- 教学策略参考 [IES 学习与记忆实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)、[EEF 元认知指导](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition)与 [EEF 反馈指导](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/feedback)，转写为本项目的原始提示词；尚未评估本应用的实际教学效果。
- 自动选择采用本地关键词规则，无额外路由模型请求；模型表现与提示遵循程度取决于自行配置的服务。长资料会受上下文预算影响，不能保证所有背景均送入模型。
- PDF 仍优先读取原有文字层并按需提供页面图片，不引入 OCR；公式、图表和复杂阅读顺序仍需核对原页。图片阅读需要视觉模型。
- 本轮未连接物理设备，未使用真实学校账号、私有课件或真实模型服务端到端验收，发布为 prerelease。自动测试与浏览器检查不等同于真机或教学效果验收。
- 使用 AI 会将所选文字与图片发送给自行配置的模型服务，详见 [隐私说明](../PRIVACY.md)。账号、凭据、签名私钥、本地诊断与私人课程内容不上传。
