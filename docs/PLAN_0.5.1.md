# 0.5.1 手机界面与水缸修订

依据：用户 2026-10-15 的六张截图与反馈。

- 顶部仅保留搜索框和通知，搜索继续进入原有全局搜索面板。
- 手机课程和录播课程固定双列小卡片，完整换行长标题；操作入口改为明确的“管理”，保留长按。
- 底部采用无顶部分隔线的圆角导航，选中标记集中在图标，兼容 Pad 侧边栏。
- 水缸取消 24° 限制，读取完整屏幕重力方向和摇晃峰值；50 毫秒读取、逐帧弹簧插值，倒置和前后倾斜同样响应。
- 省电采用低分辨率像素水粒，均衡采用 Canvas 柔光水面，高清采用 3D 玻璃；低档不创建 WebGL。高清环境反射改为柔和光带。
- 去掉水缸的触摸高亮，不影响其他控件的键盘焦点。
- 本轮只构建 ARM64 移动 APK；后续默认只更新工作项目，需要安装包时再构建 ARM64，不在每次修改后自动打包，也不自动导出源码或压缩包。核对 artifacts 范围后将旧安装包、校验文件、源码归档和导出副本移入回收站，仅留最新安装包及其校验值。

验证：重力倒置／跨 ±π 过渡、两轴倾斜、摇晃与回稳、不同帧率的一致性；前端回归、严格 UTF-8、手机和 Pad 视觉检查、ARM64 安卓构建与签名。真机传感器响应、高清材质与耗电由实际设备继续验收，不以合成输入替代。

状态：本地实施与预览 APK 交付完成。66 项测试、前端和安卓构建、源码编码、手机／Pad 浏览器检查与安装包签名核对通过；真机结果仍待验收。详见 RELEASE_0.5.1.md。
