# 0.4.0 开源预览交付记录

日期：2026-10-15。此记录区分界面／核心逻辑验证、Android 安装验证与尚待完成的真实服务验收。

## 本轮改动

- 保留象牙白与绛红视觉，增加页面、卡片、按钮、弹窗与提示过渡；系统减少动态效果时关闭动画。
- 作业时间范围、标题／课程／代码搜索，未提交作业导出 ICS 快照。
- 课程置顶、资料列表搜索、忽略和移除的即时撤销；修复已移除课程列表的空白状态判断。
- 离线提示、界面异常恢复、弹窗焦点循环与返回入口；为 Android 10 旧 WebView 补充 Flex 间距回退。
- Android 专用首页、构建／贡献／隐私／安全／发布说明，问题和 PR 模板，前端与核心检查，手动 APK 构建入口。
- 原桌面自动发布配置归档；源码导出采用文件清单，排除账号验收记录、本机诊断、缓存、密钥和 Git 历史。
