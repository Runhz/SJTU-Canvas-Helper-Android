# Canvas 随行 · Windows

独立的 Windows 学习工作区。界面入口在 `windows-app/src`；不导入 Android 的页面、导航或播放器组件。课程请求、文件提取及教学规则使用项目已有的服务代码。

## 这一版

- 固定桌面导航，课程/学期筛选、资料、作业、笔记与下载分开组织；AI 是可收起、可横向拖动调整宽度的侧栏。
- 课程和作业读取 Canvas 实际数据。未连接时显示连接入口，不展示虚构课程、学习时长或完成数。
- 文件先在页面内请求平台预览，可在独立窗口阅读。平台限制嵌入时，提供独立阅读入口与本机下载。
- 课堂支持视频播放、机位与倍速切换、长按临时加速、全屏字幕/课件工具、并排或浮动课件、缩放与拖动、字幕选择提问、截图提问及观看位置保存。
- AI 对话保存在本机，可从历史继续；支持教学方式预览、本机文件文字提取、课堂上下文、截图粘贴/标记/裁切、输入框展开、Enter 发送和 Shift+Enter 换行，以及将问答提炼为笔记。
- Markdown 笔记提供编辑、公式预览和导出；离开页面时保存尚未保存的内容。
- 作业要求及已有提交附件可预览；支持文件选择、格式核对、主动提交和回执回查。没有取得平台成功回执时，不展示成功动画或自动重试。
- 下载到用户选择的位置；下载页提供平台预览、本机打开与删除。应用外修改过的文件不会直接删除。
- 水池使用 GPU 波浪、法线、折射和焦散，支持点击及拖动互动，离屏/后台暂停。

## Windows 服务与数据

`windows-workspace` 功能使用 `desktop::run` 启动，只注册学习工作区需要的命令；不初始化旧桌面版的账号数据库、更新器或 MCP 服务。Android 入口维持独立。

- Canvas Token、模型密钥和网页登录配置：Windows DPAPI 保护，保存在当前应用配置目录。
- 对话、笔记与观看进度：应用 WebView 的 IndexedDB，按账号及 Token 摘要隔离。
- 下载记录：当前应用数据目录的账号专属 JSON；下载文件留在用户选择的位置。
- 播放连接：需要时在本机随机空闲端口启动，只能连接固定的平台媒体域名。

## 连接

1. 在“设置与连接”填写 Canvas Token，保存并连接。
2. 需要课堂录播时，打开官方登录窗口，自行完成 jAccount 登录，返回设置点击“同步登录”。
3. 需要 AI 时，在模型服务页填写服务地址、模型名称和 Key。

“直播窗口”打开官方课堂平台的独立窗口，由用户选择当前可观看的课堂。没有登录或取得节目数据前，不显示“正在直播”的虚构状态。

文件问答沿用文字层与文档结构提取；截图以图片发送给支持图像的模型。不能据此声称模型已经看过 PDF 的全部页面图像。图像跨域限制或平台嵌入限制发生时，界面会保留替代入口。

## 构建与检查

```powershell
npm --prefix windows-app ci
npm --prefix windows-app test
npm --prefix windows-app run build
corepack yarn tauri build --debug --no-bundle --config src-tauri/tauri.windows.conf.json
```

Windows 入口即使在调试构建也使用 GUI 子系统，不显示终端窗口。当前交付的是可直接运行的 EXE，不是 MSI 安装器。

已完成前端构建、Windows EXE 编译、5 项学习逻辑测试，以及实际 DPAPI 代码的 2 项 Windows 回归测试（中文配置加密往返、损坏凭据拒绝）。32 份新增代码/配置通过严格 UTF-8 与 JSON 检查。

按用户要求，没有进行这次的界面或真实账号验收；直播节目、校内权限、实际课件、模型服务与作业提交由用户验收。
